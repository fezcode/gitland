# Gitland 0.14.5

## Windows release

Download and run **Gitland-Setup-0.14.5.exe**. The Windows x64 installer includes the .NET runtime.

## Changes

### Lavender light theme

- Add **Lavender** in **Settings → Appearance**, with warm ivory code surfaces, lavender panels, plum text, and soft sage and rose diff highlights.
- Apply the palette throughout diffs, merge editors, history, menus, and Settings. Merge sides retain distinct colors, and smaller labels use darker text for readability.
- Save the selected theme and apply changes immediately without losing unsaved merge text. Atelier remains the default.
- Match checkbox labels to the theme and keep disabled primary button labels visible against a tinted background.
