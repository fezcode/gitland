# Gitland 0.9.0

## Windows release

Download and extract **Gitland-0.9.0-win-x64.zip**, then run **gitland.exe**. The .NET runtime is included. Git must be installed and on PATH; GitHub actions also require the GitHub CLI and authentication.

## Changes

- Production startup opens a welcome page with Open, Clone, and Create repository actions. Sample data is excluded from the application assembly.
- One Merge navigation entry contains conflict resolution and three-way revision/file comparison.
- Outward arrows open expanded editors and copy source text. Source-to-result actions use downward arrows; Magic resolve uses a wand.
- Tags has a direct navigation entry and filtering by name, annotation, or commit, alongside create, edit, delete, and push actions.
- Resizable sidebar, long-form commit message window, staged-file summaries, four themes, bundled fonts, and optional Hisashi integration.
- Repository management includes branches, remotes, stashes, worktrees, history operations, recovery references, GitHub publication, and releases.
- Tmds.DBus.Protocol uses the 0.21.3 security backport for [GHSA-xrw6-gwf8-vvr9](https://github.com/advisories/GHSA-xrw6-gwf8-vvr9).

The repository is public, with source, workflow documentation, and a README banner. See README for supported formats and current limits.

## Validation

- Release build: zero warnings and errors.
- 104 core and real Git integration tests passed.
- 186 offscreen native UI checks passed, including empty production startup, Tags search, compact merge layout, staging, committing, conflict resolution, and three-way navigation.
- Portable ZIP contents and CRC validated; a SHA-256 checksum is attached to this release.
