# Gitland 0.14.2

## Windows release

Download and run **Gitland-Setup-0.14.2.exe**. The installer places Gitland in `%LOCALAPPDATA%\Programs\Gitland`, creates the shortcuts you select, and registers an uninstall entry in Apps & Features. The .NET runtime is included.

## Changes

### Review a commit directly from its graph

Selecting a commit now opens an embedded file-by-file diff beneath the graph. The review uses the full workspace width, with resizable graph and file-list dividers. Switch between side-by-side and unified views, search the source, navigate change regions, fold unchanged context, or ignore whitespace. Additions and deletions keep their distinct colors and word-level highlights.

Merge commits offer a parent selector; initial commits compare against an empty tree. Comparisons use pinned commit IDs and exclude uncommitted working-tree changes. Renames retain their original paths, and binary files explain why a text comparison is unavailable. Commit and repository actions remain available beside the review.

### Clearer history and responsive navigation

- Commit and changed-file selection span the entire row.
- Colored branch lanes keep their identity as graph columns shift. Curved connections, distinct merge nodes, and branch/tag badges make ancestry easier to follow.
- Up/Down and Home/End navigate visible commits. Rapid selections keep the latest requested diff.
- Short diffs start at the top of their pane, including at compact window sizes.
- Buttons, graph emphasis, and arriving diff content use brief transitions. **Settings → Appearance → Reduce motion** disables them immediately and persists across restarts.
- Sidebar hover changes immediately, fixing the overlapping highlights caused by the previous tab's fading hover state. The selected tab keeps a steady highlight.
