# Gitland 0.9.1

## Windows release

Download and run **Gitland-Setup-0.9.1.exe**. The installer places Gitland in `%LOCALAPPDATA%\Programs\Gitland`, creates the shortcuts you select, and registers an uninstall entry in Apps & Features. The .NET runtime is included. Git must be installed and on PATH; GitHub actions also require the GitHub CLI and authentication.

This release replaces the portable ZIP with the installer. Gitland now ships the same way as the other Fezcode desktop applications.

## Changes

- A Forge installer built from `forge.toml`: Mica wizard chrome, a folder step, optional Desktop and Start menu shortcuts, and an option to open Gitland when setup finishes.
- Uninstall removes the installed files and, only when you ask it to, your settings. The uninstaller previously pointed at a directory Gitland never creates; it now targets the real settings location, `%LOCALAPPDATA%\Gitland`.
- `installer.ps1` builds, tests, publishes the self-contained payload, and packages Setup, refusing to package a version mismatch, a framework-dependent payload, or a Setup that is not a GUI executable.
- `version.ps1` moves the release version through every place it is written by hand and verifies those places agree.
- `build.ps1 -Payload` publishes the self-contained payload to `dist/win-x64`, stopping only a Gitland already running from that directory.
- `AGENTS.md` documents the release flow.

No application behavior changed in this release.

## Validation

- Release build: zero warnings and errors.
- 104 core and real Git integration tests passed.
- 186 offscreen native UI checks passed.
- Setup verified as a GUI-subsystem executable and reported with its SHA-256 checksum.
