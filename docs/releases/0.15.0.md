# Gitland 0.15.0

## Windows release

Download and run **Gitland-Setup-0.15.0.exe**. The Windows x64 installer includes the .NET runtime.

## Changes

### Settings moved to the Fezcode folder

- Settings now live in `%APPDATA%\fezcode\Gitland\settings.json`, alongside the other Fezcode apps. Logs and caches, if Gitland ever writes any, go to `%LOCALAPPDATA%\fezcode\Gitland`.
- On first launch Gitland moves your existing settings from `%LOCALAPPDATA%\Gitland` automatically and removes the old folder. If settings already exist in the new location, they are kept and the old copy is discarded. A failed move never stops Gitland from starting.
- The uninstaller's "remove my settings" option now clears `%APPDATA%\fezcode\Gitland`.
