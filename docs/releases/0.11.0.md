# Gitland 0.11.0

## Windows release

Download and run **Gitland-Setup-0.11.0.exe**. The installer places Gitland in `%LOCALAPPDATA%\Programs\Gitland`, creates the shortcuts you select, and registers an uninstall entry in Apps & Features. The .NET runtime is included.

## Gitland can install Git for you

Gitland runs every operation through Git, so without it the application cannot do anything — and until now it could only tell you to go and get it.

**Settings → Git** reports whether Git is on your PATH, which version, and whether a newer release exists, then installs or updates it for you. It uses winget where available and otherwise downloads the official 64-bit installer from the Git for Windows project on GitHub. It refuses any download that is not served over HTTPS from GitHub, and refuses to run a downloaded file that is not a Windows executable. Windows asks for administrator permission as usual; Gitland never bypasses that prompt.

After a first install, restart Gitland so it picks up the updated PATH.

## Everything from 0.10.0, now reachable

0.10.0 added the operations. This release puts them in front of you.

- **Repository → Rewrite**: interactive rebase with a plan you can reorder row by row and set to pick, reword, edit, squash, fixup or drop; hard reset; amend that can fold in the staged index; cherry-pick a run of commits; revert, including a merge commit by choosing which parent to keep; and the reflog.
- **Repository → Advanced**: bisect with good, bad and skip; submodules to add, update and sync; Git LFS patterns; patch export and apply; archive a revision as a zip; hooks; and commit signature verification.
- **Repository → Remotes**: fetch with prune, a pull dialog offering fast-forward, merge or rebase with an option to stash your changes first, and a forced push that states plainly that it uses `--force-with-lease` and will refuse to overwrite commits the remote gained since your last fetch.
- **Working changes**: a **Changes** menu carrying discard for the selected file, for everything, and for untracked files; and each hunk now offers **Unstage** and **Discard** beside **Stage**.
- **Blame** and **History of selected file** from the Changes menu.

- Setup verified as a GUI-subsystem executable and reported with its SHA-256 checksum.

## Note for anyone driving Gitland headlessly

The repository watcher added in 0.10.0 refreshes the view when files change on disk. `GITLAND_DISABLE_WATCH=1` turns it off, which is what Gitland's own offscreen validation harness now does so its assertions are not raced by a background refresh.
