# Gitland 0.14.1

## Windows release

Download and run **Gitland-Setup-0.14.1.exe**. The installer places Gitland in `%LOCALAPPDATA%\Programs\Gitland`, creates the shortcuts you select, and registers an uninstall entry in Apps & Features. The .NET runtime is included.

## Changes

### Workspace says it is scanning

Opening the Workspace used to draw the table before the first scan had answered, so for the few seconds a large folder takes to read it announced *No repositories here* — about a folder that holds a hundred of them. While a scan runs, the view now says **Scanning for repositories** with a progress bar, the line under the folder reads *Scanning for repositories…*, and the status bar names the folder being read. Rescan and the Fetch, Pull and Push all buttons wait until the scan is done. Rescanning a folder that is already listed keeps the table on screen while it refreshes.

### Workspace fits a narrow window

At small window sizes the header's buttons pushed the folder path down to a single ellipsis, and five fixed-width columns left the repository column with no width at all, so names were drawn on top of the branch column.

- Below about 820 pixels the buttons move onto their own row beneath the folder path.
- A long repository name is trimmed with an ellipsis instead of spilling into the next column. Its full path is still in the row's tooltip.
- As the window narrows, the columns that matter least give way first: Remotes, then Sync. Branch and Changes narrow rather than disappear, so the repository name always keeps its room.

## Validation

- Release build: zero warnings and errors.
- 203 core and real Git integration tests passed.
- 252 offscreen native UI checks passed, including new checks that the first render reports a scan rather than an empty folder, and that a narrow window keeps room for repository names and drops the Remotes column.
- Setup verified as a GUI-subsystem executable and reported with its SHA-256 checksum.
